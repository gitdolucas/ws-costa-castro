# Costa Castro

Site e vitrine experimental da Costa Castro, em Next.js.

## Desenvolvimento

```bash
npm install
npm run dev
```

A vitrine consome o catálogo da Cara Certa no servidor. Configure `CARA_CERTA_API_URL`, `CARA_CERTA_ORG`, `CARA_CERTA_SITE_TOKEN` e `REVALIDATE_SECRET` fora do Git. Previews protegidos também usam `CARA_CERTA_BYPASS_SECRET`.
